# Changelog

## 1.0.0

First public release.

- Four themes: Dark, Paper, Green and Light.
- Zed: two blur variants for every theme (Blur V1 = light blur, Blur V2 = strong blur), 12 themes in total.
- JetBrains: the four base themes (JetBrains IDEs cannot do window transparency).
- App icon, sample files for 37 languages and demo screenshots.
